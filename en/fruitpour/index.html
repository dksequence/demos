About the app

Fruitpour is a calm sorting puzzle. Tap a bottle to pour, and gather each juice color into a single bottle. That is the whole rule set; the depth comes from the order you pour in.

Each level changes the number of colors and empty bottles, and later levels hide everything below the top layer. When you get stuck, use undo, restart, or a hint.

Features

  • One-hand control: tap a bottle to pour
  • 600 levels
  • Undo, restart and hints
  • Bold fruit marks for when colors look alike
  • Progress backup code
  • 12-language support
