About the app

Gemgrove is a match 3 puzzle with no timer. No clock ticking in the corner, no seconds draining while you think. You get a set number of moves and all the time in the world to spend them well.

Every gem has its own shape as well as its own color: a circle, a rounded square, a triangle, a diamond and a hexagon. You can still read the board with the color turned off. Travel from Korea to Iceland and meet a different board shape in every country.

Features

  • Match 3 with no timer, only a set number of moves
  • Five gems told apart by shape as well as color
  • Hammer, swap and shuffle boosters
  • Line breakers, color gems and bombs from 4-, 5- and cross matches
  • 20 countries, 600 levels, 12 languages
